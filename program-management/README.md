# Program Management Archive

## Purpose

This directory contains internal project-management, readiness-review, planning, and decision-tracking documents used during the TrueCalling SOC 2 readiness effort.

These files are retained for historical traceability and project governance purposes.

## Scope

This directory may contain:

* Readiness reviews
* Remediation planning
* Human Owner decisions
* Audit preparation notes
* Project checkpoints and status reports
* AI-assisted review artifacts

## Not Audit Evidence

Files in this directory are internal working documents and should not be considered formal SOC 2 evidence unless explicitly referenced by approved compliance documentation.

## Access

This repository must remain private.

These documents may contain internal assessments, remediation discussions, and security observations that are not intended for public disclosure.

## Retention

Documents are retained to preserve project history, decision rationale, and readiness activities.
